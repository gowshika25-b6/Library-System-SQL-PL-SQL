# Library-System-SQL-PL-SQL
Library Management System using SQL and PL/SQL with joins, cursors, and exception handling.

## Project Description
This project demonstrates both SQL and PL/SQL concepts by managing books, members, and issue records.

## Features
- Created BOOKS, MEMBERS, and ISSUES tables
- Used joins for data retrieval
- Implemented PL/SQL blocks for operations
- Added cursor and exception handling

## Concepts Used
- SQL joins and aggregate functions
- PL/SQL blocks and conditions
- Cursors and exception handling

## Learning Outcome
- Combined SQL and PL/SQL knowledge
- Built real-time database system
- Improved database management skills
